## Featured projects

### [CSS Utilities + Static Site Generator](https://github.com/RITESH-del/CSS-Utilites-SSG)

A themeable CSS component library paired with a Markdown/EJS static-site generator. It builds reusable theme bundles and documentation pages.

**Stack:** Node.js · EJS · Markdown-It · CSS · [Live demo](https://ritesh-del.github.io/CSS-Utilites-SSG/)

### [TB Detection Model](https://github.com/RITESH-del/PRJ-1-project)

Research code for chest-X-ray TB classification: patient-grouped dataset preparation, configurable image preprocessing, DINOv2/DenseNet training, inference, and evaluation workflows. **Research prototype; not for clinical use.**

**Stack:** Python · PyTorch · OpenCV · Transformers · scikit-learn

### [SnackStream — Android coursework prototype](https://github.com/RITESH-del/AndroidCourseProject)

A Java Android app experiment with authentication and navigation, a reels/stories feed, and snack-ordering cart flows.

**Stack:** Java · Android · Firebase
